# Lesson 2 — N-gram Language Models with NLTK

Nebius ML course, Lesson 2 (March 2025).

Implements an N-gram language model using NLTK, trained on the Donald Trump tweet corpus. Covers tokenization, n-gram statistics, and text generation.

## Contents

- `Ngram_Language_Model_with_NLTK.ipynb` — main notebook
- `Donald-Tweets!.csv` — training corpus (public dataset)
- `kilgariff_ngram_model.pkl` — serialized trained model
- `language-never-random.txt` — reference reading
